# MyTeam_Cummins

A warm and personal team appreciation web page built as a static single-page website for GitHub Pages.

## What this project does
This page is designed to make each team member feel appreciated and valued. It contains a collection of personalized team cards, each with:

- a member name
- a custom motivational quote
- a password-protected unlock flow
- a special final message after closing an unlocked card
- a celebratory premium UI with love-themed background effects

## Purpose
The goal is to create a happy, emotional experience where teammates open their own card, read a personalized message, and feel recognized and appreciated by the team.

## Features
- Responsive single-page layout
- Elegant dark luxury design
- Personalized quote cards for each team member
- Password unlock interaction for each member
- Final note popup after reading a card
- Background floating heart animations
- Celebration finish screen after all cards are unlocked
- Easy deployment on GitHub Pages

## Files
- `index.html` - main page with HTML, CSS, and JavaScript
- `bhagabhaga.mp3` - background music file used by the page

## Run locally
Open `index.html` in a browser, or serve the folder using a simple local server if you want the media to behave more reliably.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages
To publish on GitHub Pages:

1. Push this folder to your GitHub repository.
2. In the repository settings, enable GitHub Pages.
3. Select the main branch (or the branch you use) as the source.
4. Your website will be published as a static site.

## Note
This is a static page and does not require any framework or build step.
